使用说明

  1. 配置 API：右上角「设置」填入 DeepSeek API Key（也可写进项目根目录 .env 的 DEEPSEEK_API_KEY）。
  2. 上传：拖入 PDF；论文很长时可只填页码范围，先逐章试跑。
  3. 翻译：点文档卡片上的「开始翻译」，逐段进行；中途可以停，之后「继续翻译」接着跑。
  4. 阅读：进入阅读页后左英右中逐段对齐；选中任意句子会浮出「问 AI」按钮；j/k 上下段，[/] 调字号。
  5. 带走：「导出 HTML」得到可独立打开的双栏文件（公式用 MathJax 渲染，服务在跑时仍可问 AI）。

公式保真说明：左栏原文由 PDF 内部字体与基线信息还原（CMMI/CMSY 等数学字体识别 + 上下标重建 + Unicode→LaTeX 映射），不依赖模型猜测；扫描件或矢量图形公式建议打开「公式修复」让模型参与重写。

开始使用 EasyEssay

不用注册、不用登录。填一次你自己的 DeepSeek API Key 就能用； 密钥只保存在这台电脑的 data/settings.json 里，不会上传到任何地方。
